 📈 BULL-BEAR Stock Market Simulator

This is a Java-based console application that simulates a simple stock market system. The project allows users to buy and sell stocks, track their investments, and experience how stock prices change over time. It also includes an admin panel to manage stocks and users.

---

 🚀 Features

* 🔐 **User System**
  Users can sign up, log in, and manage their accounts securely.

* 📊 **Stock Trading**
  Buy and sell shares of popular companies like Amazon, Apple, Google, Microsoft, and Tesla, with instant balance updates.

* 📉 **Price Simulation**
  Stock prices change automatically to simulate real market behavior.

* 👨‍💼 **Admin Controls**
  Admin can add new stocks, update prices, and view user data.

* 💼 **Portfolio Tracking**
  Users can check their investments, current value, and profit or loss.

* 🧾 **Transaction History**
  Keeps track of recent user transactions.

⚙️ Technologies Used

* Core Java
* Object-Oriented Programming (OOP)
* Arrays and basic data structures
* Timer & TimerTask for simulating real-time updates
* Console-based interface

🎯 Purpose

The main goal of this project is to understand how a stock market system works and to practice Java programming concepts like OOP and real-time simulation.


▶️ How to Run

1. Clone this repository
2. Open it in any Java IDE (IntelliJ, Eclipse, or VS Code)
3. Run `StockSim.java`
4. Choose to continue as a User or Admin
